# NutriFit Tracker

A comprehensive fitness and nutrition tracking web application.

## Features
- Track meals and workouts with calorie calculations
- Weekly goals with progress tracking
- Water intake monitoring (8 glasses/day)
- Meal and workout presets for quick logging
- Interactive calendar with daily summaries
- 7-day calorie trend charts and meal category breakdown
- Logging streak counter with achievement badges
- Motivational quotes
- Share progress with friends
- Swipe-to-delete on mobile devices
- Dark/light theme toggle

## Getting Started
1. Open `index.html` in a web browser
2. Start logging meals and workouts
3. Set your weekly goals
4. Track your progress!

## Testing
Open `tests.html` to run the automated test suite.

## Technologies
- Vanilla JavaScript (ES6+)
- Chart.js for visualizations
- LocalStorage for data persistence
- CSS3 with custom properties for theming
